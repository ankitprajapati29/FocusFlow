## 📌 About the Project

**FocusFlow** is a smart study planner that combines task management, subject organization, progress tracking, and a Pomodoro timer in one simple dashboard.

Its goal is to help students study more efficiently, stay organized, and maintain consistent study routines.

## ✨ Key Features

- 📋 **Task Management** — Add and manage daily study tasks.
- ⏱️ **Pomodoro Timer** — 25-minute focus sessions and 5-minute breaks.
- 📊 **Progress Tracking** — Monitor completed and pending tasks.
- 📚 **Subject Overview** — Organize academic activities.
- 🔍 **Search & Filters** — Find and sort tasks easily.
- 💾 **Local Storage** — Save tasks in the browser.
- 📱 **Responsive Design** — Clean, user-friendly interface.
